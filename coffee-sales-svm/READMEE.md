# Coffee Type Prediction using SVM

This project uses a Support Vector Machine (SVM) model to predict coffee types based on transaction details such as time, weekday, month, and transaction amount.

# Features

* Data cleaning and preprocessing
* Feature encoding and scaling
* SVM model training
* Hyperparameter tuning using GridSearchCV
* Accuracy evaluation
* Classification report
* Confusion matrix visualization
* Revenue and sales analysis charts
* Sample prediction system

# Technologies Used

* Python
* Pandas
* NumPy
* Scikit-learn
* Matplotlib
* Seaborn

## Dataset Features

* Hour of day
* Transaction amount
* Time of day
* Weekday
* Month name

# Model Used

* Support Vector Machine (SVM)

## Output

The model predicts the most likely coffee type based on the given sample transaction details.
